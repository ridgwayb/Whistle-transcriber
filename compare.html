Model comparison

Run the same clips through Whistle, Whisper base and Whisper small, on this device, and compare speed and accuracy.

How to use

  1. Add 4 to 6 clips: record some (quiet, street, Spanish, English, mixed) and/or upload files.
  2. Optional: under each clip, type what was actually said, to get a word error rate.
  3. Press Run. The first run downloads the models (about 340 MB in total).
  4. Press Copy results and paste the JSON back to Claude.
